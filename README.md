# Pava Photostudio

Сайт фотопростору **PAVA** у Дніпрі — фотостудії без фотографа, де клієнт сам керує зйомкою через дзеркало, камеру та пульт.

Проєкт містить публічний сайт, галерею, правила, форму бронювання, базову адмінку та заготовку під оплату через LiqPay.

---

## Що є на сайті

- Темний преміальний дизайн з бордовими акцентами.
- Адаптивна верстка для мобільних, планшетів і ПК.
- Hero-блок з великим логотипом PAVA Photostudio.
- Анімоване змінне слово в слогані: `свобода`, `магія`, `емоція`, `історія`.
- Блок про формат фотостудії без фотографа.
- Прайс на 30 / 60 / 90 / 120 хвилин.
- Галерея з фото, кнопкою “Завантажити ще” і лайтбоксом.
- Плавна анімація перемикання фото в галереї.
- Фіксовані стрілки в лайтбоксі, які не стрибають від ширини фото.
- Блок обладнання, реквізиту й фотофонів.
- Відгуки клієнтів у форматі слайдера.
- FAQ.
- Модальне вікно правил.
- Модальне бронювання.
- Футер з контактами, соцмережами й стилізованою картою-посиланням на Google Maps.

## API бронювання

| Метод | Шлях | Опис |
|---|---|---|
| `GET` | `/api/booking/config` | Тарифи, робочі години, стан LiqPay |
| `GET` | `/api/booking/availability?date=YYYY-MM-DD&package=60` | Доступні слоти |
| `POST` | `/api/booking/orders` | Створення резерву |
| `GET` | `/api/booking/orders/:publicId/status` | Перевірка статусу бронювання |
| `POST` | `/api/payments/liqpay/callback` | Callback від LiqPay |

Приклад створення бронювання:

```json
{
  "packageId": "60",
  "name": "Імʼя клієнта",
  "phone": "+380681234567",
  "email": "client@example.com",
  "date": "2026-08-15",
  "time": "14:00",
  "notes": "Коментар за бажанням"
}
```

Слот резервується на **15 хвилин**. Перетини бронювань перевіряються з урахуванням тривалості сеансу.

## LiqPay

Оплата підготовлена як scaffold. Щоб увімкнути реальну оплату, потрібно задати змінні середовища:

```env
PUBLIC_URL=https://your-domain.example
LIQPAY_PUBLIC_KEY=...
LIQPAY_PRIVATE_KEY=...
```

Без цих ключів сайт працює в підготовчому режимі: можна тестувати форму, слоти й резерви, але реальний перехід до оплати не виконується.

Реальні ключі не можна комітити в Git.

Адмінка доступна за шляхом:

```text

```

Для доступу потрібен `ADMIN_TOKEN`.


В адмінці передбачені:

- перегляд бронювань;
- перегляд/створення заблокованих слотів;
- зміна статусів записів.

## Render / Production

У репозиторії є:

- [`Dockerfile`](Dockerfile)
- [`render.yaml`](render.yaml)

Для Render використовується Docker web service.

Потрібні змінні:

```env
NODE_ENV=production
PUBLIC_URL=https://your-render-or-custom-domain
ADMIN_TOKEN=...
LIQPAY_PUBLIC_KEY=...
LIQPAY_PRIVATE_KEY=...
DB_PATH=/var/data/bookings.db
```

Для SQLite на Render потрібен persistent disk. У `render.yaml` уже вказаний диск:

```yaml
disk:
  name: pava-data
  mountPath: /var/data
  sizeGB: 1
```

## Важливі нотатки

- У репозиторії можуть лежати оригінальні фото, які ще не додані в Git. Для сайту використовуються оптимізовані `.webp` файли.
- Google Fonts під час локальних sandbox-перевірок може блокуватися мережею. Це не ламає сайт.
- GitHub Pages не підходить для повного сайту з бронюванням, бо API потребує Node.js сервера.
- Для production бажано використовувати Render або інший Node.js hosting з persistent storage.
